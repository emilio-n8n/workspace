# Armada 200

200 missions numérotées, escouades à propriété étanche (une par app + module, plus le design system et le transversal).

Règles communes: zéro régression, français irréprochable, tokens sémantiques uniquement, accessibilité complète, états vide/erreur/chargement, tests par comportement, vérification locale légère, commit sans push.

Total: 200 missions (14 escouades × 14 + 4 transversales).
